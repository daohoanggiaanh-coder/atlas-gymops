Core features

Replace paper logs and scattered spreadsheets with one connected system.

Single member database

Reception enters member, package and check-in data once. Supabase keeps it as the single source of truth.

🔔

Automatic reminders

n8n sends weekly schedules and day-before session reminders to members and trainers by email.

🎟️

Package tracking

Remaining sessions are counted automatically, with alerts before a package runs out so staff can follow up.

🛠️

Facility maintenance

Log equipment issues in seconds, schedule recurring checks and get notified before maintenance is overdue.

📊

Live owner dashboard

Attendance, revenue by package and trainer workload sync to Google Sheets — no new tool to learn.
